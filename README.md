# Goshawk Studio — legal document pages

Hosted legal document pages (Privacy Policy, Terms of Use) for Goshawk Studio's apps, served via GitHub Pages, structured as one subfolder per app (e.g. `app1/`) so the site scales as more apps are added without changing existing apps' URLs.

App-identifying details are intentionally omitted from these pages for now (folders are named generically, e.g. `app1`) and will be filled in — including renaming the folder to match the real app name — once each app is ready to be submitted for store review.
