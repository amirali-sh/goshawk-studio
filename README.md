# Goshawk Studio — legal document pages

Hosted legal document pages (Privacy Policy, Terms of Use) for Goshawk Studio's apps, served via GitHub Pages, structured as one subfolder per app so the site scales as more apps are added without changing existing apps' URLs.

New apps not yet ready for store submission should use a generic placeholder folder name (e.g. `app1/`) with app-identifying details omitted from the page content, then get renamed to the real app name (folder path and in-page branding both) once that app is actually being submitted — see `money-decisions/` for the completed example.
